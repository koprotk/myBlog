# myBlog
My blog project, consist in the creation of my own post on org mode and then publish it with a small script in python, the title, and the tags are managed automatically by the scrip though the package orgparse. The export from org to html is made by emacs. The process is completely unpainful. 

How to run it? On a terminal run:

    python3 scripts/publish_on_bloggerv2.py myorgfile.org

And that it.
