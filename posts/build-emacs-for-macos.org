* Why Bother Compiling Emacs on macOS When Homebrew Exists?
Honestly? You probably don’t need to. Homebrew does a solid job. But if you’re chasing:

- Stability
- Speed
- Compatibility
...then compiling might be worth your time.

Is compiling the holy grail? Nope. It takes time, patience, and a bit of curiosity. It’s not for folks who want things yesterday. Think of it like cooking gourmet food—sure, you could microwave something, but where’s the fun in that?

I ran into a weird issue the other day that only compiling Emacs from source could fix. Could I have passed some fancy flags to Homebrew? Maybe. But hey, the old-school way still works—and it feels good.

* Is It Hard?
Not really. Thanks to this awesome repo: [[https://github.com/jimeh/emacs-builds][Build Emacs for macOS]], the process is way easier than you'd expect. We’ll use it to build a shiny, self-contained ~Emacs.app~.

* Let’s Do This
1. First, make sure you’ve got [[https://brew.sh/][Homebrew]] installed.
2. Then run this command in your terminal:
   #+begin_src bash
   bash brew install --cask jimeh/emacs-builds/emacs-app
   #+end_src
3. That’s it. Homebrew handles the rest.

* Want to Go Deeper?
Yep, you can build it manually (like I did). If you're curious about doing it completely from scratch—no Homebrew involved—drop a comment. I might write a full tutorial on that too.
