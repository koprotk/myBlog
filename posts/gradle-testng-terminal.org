* Commands
** Running a TestNG Test
Run this from the root folder of your project:
#+begin_src bash
java -cp "./build/libs/dependencies/*:./build/classes/java/main:./build/resources/main"
-Dconfig.dir=./build/classes/java/main/com/folder1/folder2/config
-Dtestng.test.classpath=./test/com/folder1/folder2/core/suites org.testng.TestNG
-testclass classpath#methodname
#+end_src
To run all methods in a class, remove everything after the # character.
Replace ~folder1~, ~folder2~ with your actual project structure.
The ~-Dtestng.test.classpath~ should point to the folder containing your ~testng.xml~ file.

** Debugging with JDB
1. Start the debugger from the root folder:
#+begin_src bash
jdb -sourcepath "./build/classes/java/main:./build/resources/main"
-classpath "./build/libs/dependencies/*:./build/classes/java/main:./build/resources/main"
#+end_src

2. Set breakpoints in the terminal like this:
#+begin_src bash
stop at fully.qualified.ClassName:lineNumber
#+end_src

3. Run the test with debugging enabled:
#+begin_src bash
run -Dtestng.test.classpath=./test/com/folder1/folder2/core/suites
-Dconfig.dir=./build/classes/java/main/com/folder1/folder2/config
org.testng.TestNG -testclass classpath
#+end_src

- List all breakpoints: ~clear~
- Resume execution: ~cont~
- Need help? Type: ~h~
