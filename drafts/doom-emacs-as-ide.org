* Introduction
An /IDE/ is an acronymous of /Integrate Development Environment/, is a piece of software that is intendment to be a support for programming, the kind of software in summary is a bunch of tools that make the programming task more easily, notable examples, are: VSCode, IntelliJ, Eclipse, etc. of course /Emacs/ is not an /IDE/ is just a text editor, but this flexibility to be transformed with elisp code in whatever you want allow to the emacs community and thankfully to Microsoft for the creation of the standard Language Server Protocol (LSP) our emacs can be a great IDE for work to. I used as my daily programming tool in Java, but its true that it's not superior for non open-source alternatives like IntelliJ, but with a little of work, can be closer to these tools, and even more, in the AI era I'm pretty sure that this kind of open-source tools will be the future, because will be more like a building material for everyone.

In doom Emacs is easily to prepare our Emacs as an IDE, we just need to modifies our ~init.el~. To access to this file just press: ~SPC f P~ (like welcome dashboard said). Every modification in our ~init.el~ should be synced to take effect, so after modified this file you need to press ~SPC h r r~ or close Emacs and in the terminal type:

#+begin_src shell
doom sync
#+end_src

If you look at your ~init.el~ file you need to uncomment the lines of the desired features, in addition you need to add some flags in the form of ~+flag~ besides the option enabled. To figure out what flags need the desired feature you can press ~SPC h d m~ to browse in the doom module documentation.

* Eglot vs LSP-mode
In emacs exist two ways to connect to a language server: through ~LSP-mode~ or in-build ~eglot~. ~LSP-mode~ was the first development for emacs to work with a LSP on emacs, has more time in the community so this could lead a better support and a more stable packages, by the other hand the in-build wrapper eglot, is more modern, fast, and simple than ~LSP-mode~, in my case, is my option taken. I want to highlight that eglot is not better for LSP-mode, but I prefer it for two reasons (1) is built-in and (2) is faster than LSP-mode.
